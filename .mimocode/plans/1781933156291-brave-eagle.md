## Step 3: Create Formatting Utilities (`src/lib/formatUtils.ts`)

### `formatTime(time: string, format: TimeFormat): string`
Input: `"HH:mm:ss"` or `"HH:mm"` (24h string from DB)
Output based on format:
- `'24h'` → `"13:23"` (default, passthrough)
- `'en_12h'` → `"01:23 PM"`
- `'cn_24h'` → `"下午 13:23"`
- `'cn_12h'` → `"下午 01:23"`
- `'cn_natural'` → `"下午三点二十三分"` (Chinese number characters for hour/minute)

### `formatDisplayDate(dateStr: string, format: DateFormat, t: TFunction): string`
Input: `"YYYY-MM-DD"` string
Output based on format:
- `'relative'` → "今天" / "昨天" / "前天" / fall back to `'yyyy_slash_mm_dd'`
- `'yyyy_slash_mm_dd'` → `"2025/03/24"`
- `'yyyy_dash_mm_dd'` → `"2025-03-24"`
- `'mm_dd_yyyy'` → `"03/24 2025"`
- `'mm_dd'` → `"03/24"`

### `formatTimezoneOffset(tz: string, format: TimezoneFormat): string`
Input: IANA timezone string (e.g., `"Asia/Shanghai"`)
Output based on format:
- `'short_offset'` → `"+8"` / `"-5"` / `"+5:30"` (no leading zero, strip `:00`)
- `'iana'` → `"Asia/Shanghai"`
- `'compact'` → `"+0800"` / `"+0530"`
- `'gmt'` → `"GMT+8"` / `"GMT+5:30"`
- `'utc_colon'` → `"UTC+5:30"` (always has colon)
- `'iso_colon'` → `"+08:00"` (always has colon, 2-digit)
- `'cn_zone'` → `"东八区"` / `"西五区"` (Chinese zone name)
