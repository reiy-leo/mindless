# 倒数日智能分组实现计划

## 概述

为倒数日页面添加侧边栏分组功能，包括：
- **智能分组**（客户端过滤）：已完成、已删除、收藏
- **内置分组**（DB 行，`is_preset=1`）：节日、生日、纪念日、统计
- **用户自定义分组**：支持增删改，使用 emoji + 名称 + 颜色

## 设计决策

- 智能分组 = 客户端过滤器（类似 MediaSidebar 的 `SMART_GROUPS`）
- 内置分组 = DB 预设行 + `is_preset` 标志（类似 `media_groups`）
- 软删除（`deleted_at`）替代硬删除，支持"已删除"分组
- `is_favorite` 字段支持"收藏"分组
- `is_completed` 字段支持"已完成"分组（用户手动标记）
- 侧边栏布局参考 `MediaSidebar`：上方智能分组，下方可折叠分组列表

### 1. 数据库迁移 — `src-tauri/src/db/migrations.rs`

添加 `countdown_groups` 表 + `countdowns` 新列：

```sql
-- 新表
CREATE TABLE IF NOT EXISTS countdown_groups (
    id TEXT PRIMARY KEY,
    name TEXT NOT NULL,
    color TEXT DEFAULT '#3B82F6',
    icon TEXT DEFAULT '📅',
    is_preset INTEGER NOT NULL DEFAULT 0,
    sort_order REAL NOT NULL DEFAULT 0,
    created_at TEXT DEFAULT (datetime('now')),
    updated_at TEXT DEFAULT (datetime('now'))
);

-- countdowns 新增列（增量 ALTER）
ALTER TABLE countdowns ADD COLUMN group_id TEXT REFERENCES countdown_groups(id);
ALTER TABLE countdowns ADD COLUMN is_favorite INTEGER NOT NULL DEFAULT 0;
ALTER TABLE countdowns ADD COLUMN is_completed INTEGER NOT NULL DEFAULT 0;
ALTER TABLE countdowns ADD COLUMN deleted_at TEXT;

-- 索引（单独批次）
CREATE INDEX IF NOT EXISTS idx_countdowns_group_id ON countdowns(group_id);
CREATE INDEX IF NOT EXISTS idx_countdowns_deleted_at ON countdowns(deleted_at);

-- 预设分组
INSERT OR IGNORE INTO countdown_groups (id, name, color, icon, is_preset, sort_order) VALUES
    ('preset-holiday', '节日', '#EF4444', '🎉', 1, 1),
    ('preset-birthday', '生日', '#EC4899', '🎂', 1, 2),
    ('preset-anniversary', '纪念日', '#8B5CF6', '💍', 1, 3),
    ('preset-stats', '统计', '#3B82F6', '📊', 1, 4);
```


新增 `toggle_countdown_favorite` — 切换收藏状态
