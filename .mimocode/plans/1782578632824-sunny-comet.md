# Fix: Overlay windows position before visible

## Problem
In `overlayManager.ts:showOverlay()`, the order is:
1. `wv.show()` → window visible at stale position (flash/jump)
2. `emit()` → page handler runs `setPosition()` → window jumps to correct spot

## Fix — 1 file, 3 lines reordered

**File:** `src/lib/overlayManager.ts` — `showOverlay()` function (line 56-67)

Change from:
```ts
await wv.show()
await wv.setFocus()
await emit(`${label}:show`, payload)
```

To:
```ts
await emit(`${label}:show`, payload)   // page sets position while window still hidden
await wv.show()                         // window appears at correct position
await wv.setFocus()
```

**Why this works:** All 6 overlay pages register their `listen()` handlers in `useEffect` at mount time (when the overlay is pre-created with `visible: false`). By the time the user triggers `showOverlay()`, listeners are already registered. The `emit()` delivers the payload, the page computes position and calls `win.setPosition()` — all while the window is still hidden. Then `show()` makes it visible at the correct position.
