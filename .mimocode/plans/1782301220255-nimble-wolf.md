# Plan: Multi-Provider Sync (GitHub/GitLab/Gitee)

## Overview
在 Settings → Sync 页面添加 GitHub/GitLab/Gitee 三个 radio 选项，每个选项显示对应的 URL 和 Token 输入框。

## Architecture
创建 provider adapter 模式：`SyncProvider` 接口 + 三个实现类。

## File Structure
```
src/lib/sync/
  types.ts       — SyncProvider 接口 + ProviderType
  github.ts      — @octokit/rest adapter
  gitlab.ts      — @gitbeaker/rest adapter
  gitee.ts       — fetch-based adapter (Gitee API v5)
  index.ts       — getProvider() factory + parseRepoUrl
```

## Implementation Steps

### Step 1: Create sync provider types (`src/lib/sync/types.ts`)
```ts
export type ProviderType = 'github' | 'gitlab' | 'gitee'
export interface SyncProvider {
  testConnection(owner: string, repo: string): Promise<{ success: boolean; error?: string }>
  uploadFile(owner: string, repo: string, path: string, content: string, message: string): Promise<void>
  uploadBinaryFile(owner: string, repo: string, path: string, base64: string, message: string): Promise<void>
  deleteFile(owner: string, repo: string, path: string, sha: string, message: string): Promise<void>
  getFileContent(owner: string, repo: string, path: string): Promise<string | null>
  getFileSha(owner: string, repo: string, path: string): Promise<string | undefined>
}
```

### Step 2: GitHub adapter (`src/lib/sync/github.ts`)
- Move existing `@octokit/rest` logic from `syncService.ts` into `GitHubProvider` class

### Step 3: Install gitbeaker + GitLab adapter (`src/lib/sync/gitlab.ts`)
- `npm i @gitbeaker/rest`
- Use `Gitlab` from `@gitbeaker/rest` with `{ token: pat }`

### Step 4: Gitee adapter (`src/lib/sync/gitee.ts`)
- Pure `fetch`, base URL: `https://gitee.com/api/v5`
- Endpoints use `?access_token={pat}` query param
- APIs: GET/POST/PUT/DELETE `/repos/{owner}/{repo}/contents/{path}`

### Step 5: Factory + wrappers (`src/lib/sync/index.ts`)
- `getProvider(type, pat)` factory
- `parseRepoUrl(url)` with domain detection
- `testConnection()` and `syncToRepo()` wrappers

### Step 6: Update `src/lib/syncService.ts`
- Re-export from `src/lib/sync/index.ts` for backward compat

### Step 7: Add i18n keys (zh/en/ja)
```json
{
  "provider_github": "GitHub",
  "provider_gitlab": "GitLab",
  "provider_gitee": "Gitee"
}
```
Update `invalid_url` message to include Gitee.

### Step 8: Update SettingsPage.tsx
- Add `syncProvider` state (persisted to localStorage as `mindless-sync-provider`)
- Add radio selector UI (hidden radio + styled label pattern, same as language selector)
- Dynamic URL placeholder based on provider
- Pass `syncProvider` to `testConnection()` and `syncToRepo()`
- Auto-detect provider from URL input

## Key Design Decisions
- PAT storage keyed by domain (`savePat(domain, pat)`) — works for all providers
- Provider defaults to `github` for backward compat
- URL auto-detection switches provider radio automatically
- Gitee uses native `fetch` (no new dependency)
