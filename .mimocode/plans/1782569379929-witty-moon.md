# Bug fix: 切换任务时 title 被旧值覆盖

## 问题
`TaskDetailPanel` 中 `activeTaskIdRef` 在 effect 中同步更新为新 task id，但 `editTitle` 是 setState（异步批处理）。切换任务时，如果 blur 在 state 更新前触发，guard `activeTaskIdRef.current !== activeTask.id` 为 false（ref 已更新），但 `editTitle` 仍是旧 task 的 title → 旧 title 覆盖新 task。

## 修改文件
- `src/pages/TasksPage.tsx`

## 实现（line 222-249）

核心思路：在 layoutEffect 中检测 task id 变化，同步将 `editTitle` 设为新值（setState 在 layoutEffect 中是同步的，React 18 起），确保 ref 和 state 在浏览器处理 blur 之前一致。

```tsx
const [editTitle, setEditTitle] = useState(activeTask.title)
const titleInputRef = useRef<HTMLInputElement>(null)
const activeTaskIdRef = useRef(activeTask.id)

useLayoutEffect(() => {
  if (activeTaskIdRef.current !== activeTask.id) {
    activeTaskIdRef.current = activeTask.id
    setEditTitle(activeTask.title)
  }
}, [activeTask.id, activeTask.title])

useEffect(() => {
  setEditTitle(activeTask.title)
}, [activeTask.title, activeTask.id])
```

流程：
1. task 从 A 切到 B → component re-render with taskB
2. `useLayoutEffect` 同步执行（paint 之前）：检测 id 变化 → ref 更新 + editTitle 同步设为 taskB.title
3. browser paint → blur 事件触发
4. `handleTitleBlur` 中 `editTitle` 已是 taskB.title → guard 通过 → `editTitle.trim() === activeTask.title` → 不执行更新

## 验证
1. 快速连续切换多个任务
2. 在 title 输入框聚焦状态下切换任务 → 不会覆盖
3. 正常编辑 title → 功能不受影响
