# Notes Page Implementation Plan

## Overview
Add a new Notes page to Mindless with smart note groups, user-created note groups, and rich-text notes supporting tags and sub-notes.

## Database Schema

### New Tables (add to `src-tauri/src/db/migrations.rs`)

**note_groups** - user-created note containers (like habit_groups):
```sql
CREATE TABLE IF NOT EXISTS note_groups (
    id TEXT PRIMARY KEY,
    name TEXT NOT NULL,
    color TEXT DEFAULT '#3B82F6',
    icon TEXT DEFAULT '📁',
    sort_order REAL NOT NULL DEFAULT 0,
    is_archived INTEGER NOT NULL DEFAULT 0,
    created_at TEXT NOT NULL DEFAULT (datetime('now')),
    updated_at TEXT NOT NULL DEFAULT (datetime('now'))
);
CREATE INDEX IF NOT EXISTS idx_note_groups_sort_order ON note_groups(sort_order);
```

**notes** - notes with hierarchical sub-notes:
```sql
CREATE TABLE IF NOT EXISTS notes (
    id TEXT PRIMARY KEY,
    title TEXT NOT NULL DEFAULT '',
    content TEXT DEFAULT '',
    group_id TEXT REFERENCES note_groups(id) ON DELETE SET NULL,
    parent_id TEXT REFERENCES notes(id) ON DELETE CASCADE,
    tag_ids TEXT,
    is_completed INTEGER NOT NULL DEFAULT 0,
    is_archived INTEGER NOT NULL DEFAULT 0,
    level INTEGER NOT NULL DEFAULT 0,
    sort_order REAL NOT NULL DEFAULT 0,
    created_at TEXT NOT NULL DEFAULT (datetime('now')),
    updated_at TEXT NOT NULL DEFAULT (datetime('now')),
    completed_at TEXT,
    deleted_at TEXT
);
CREATE INDEX IF NOT EXISTS idx_notes_group_id ON notes(group_id);
CREATE INDEX IF NOT EXISTS idx_notes_parent_id ON notes(parent_id);
CREATE INDEX IF NOT EXISTS idx_notes_deleted_at ON notes(deleted_at);
CREATE INDEX IF NOT EXISTS idx_notes_is_archived ON notes(is_archived);
CREATE INDEX IF NOT EXISTS idx_notes_is_completed ON notes(is_completed);
```

### 2. Commands (`src-tauri/src/commands/notes.rs`) - NEW FILE

**Note Group commands:**
- `get_note_groups(app) -> Result<Vec<NoteGroup>, String>` - all non-archived groups
- `create_note_group(app, name, color?, icon?) -> Result<NoteGroup, String>`
- `update_note_group(app, id, name?, color?, icon?, is_archived?) -> Result<NoteGroup, String>`
- `delete_note_group(app, id) -> Result<(), String>` - hard delete

**Note commands:**
- `get_notes(app) -> Result<Vec<Note>, String>` - all non-deleted, non-archived notes (top-level: parent_id IS NULL)
- `get_all_notes(app) -> Result<Vec<Note>, String>` - all non-deleted notes (for smart group counts)
- `get_note_by_id(app, id) -> Result<Note, String>`
- `get_sub_notes(app, parent_id) -> Result<Vec<Note>, String>` - children of a note
- `get_all_sub_notes(app, note_ids: Vec<String>) -> Result<Vec<Note>, String>` - batch fetch
- `create_note(app, title, content?, group_id?, parent_id?, tag_ids?) -> Result<Note, String>`
- `update_note(app, id, title?, content?, group_id?, tag_ids?, is_completed?, is_archived?, sort_order?) -> Result<Note, String>`
- `delete_note(app, id) -> Result<(), String>` - soft delete (set deleted_at)
- `archive_note(app, id) -> Result<Note, String>` - set is_archived = 1
- `unarchive_note(app, id) -> Result<Note, String>` - set is_archived = 0
- `complete_note(app, id) -> Result<Note, String>` - toggle is_completed, set completed_at

### 3. Module registration
- `src-tauri/src/commands/mod.rs` - add `pub mod notes; pub use notes::*;`

### 7. NotesPage (`src/pages/NotesPage.tsx`) - NEW FILE

**3-panel layout** (similar to TasksPage):

**Left Panel (~200px):**
- Smart Groups section (collapsible):
  - All Notes (icon: notebook) - shows all non-deleted notes
  - Archived (icon: archive) - shows archived notes
  - Completed (icon: check-circle) - shows completed notes
- Note Groups section (collapsible):
  - List of user-created note groups with color dots
  - "+" button to create new group
  - Right-click context menu on each group: Edit, Archive/Unarchive, Delete
  - Archived groups shown in Archived smart group view
- Active state highlighting on selected group

**Middle Panel (flex-1):**
- Header: group name, note count, search input, "+" new note button
- Notes list: sorted by updatedAt desc (most recent first)
  - Each note: title, preview of content (first line), tags as chips, timestamp
  - Sub-notes shown as indented flat list below parent (like TasksPage subtasks)
  - Click to select, showing detail in right panel
  - Checkbox to toggle completion
  - Inline creation: input at bottom of list

**Right Panel (resizable, ~400px):**
- Note detail editor when a note is selected:
  - Title input (editable inline)
  - Tags (TagCombobox component)
  - MilkdownEditor for content
  - Sub-notes list (add/manage)
  - Metadata: created_at, updated_at
  - Actions: archive, complete, delete buttons
- Empty state when no note selected

**Context Menu** (on note groups):
- Manual inline pattern matching TasksPage: useState for {x, y, id}, fixed overlay + positioned div
- Menu items: Edit (pencil icon), Archive/Unarchive (archive icon), Delete (trash, red)

**State Management:**
- Local useState for: selectedGroupId, selectedNoteId, contextMenu, searchQuery
- Use `useViewStore` or local state for panel widths (useAppStore for persistence)
