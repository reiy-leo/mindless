# Fix: Milkdown 中 `[]()` 没有渲染成链接

## 问题
在 Milkdown 编辑器中输入 `[text](url)` 不会自动转换为可点击的链接，空格和回车都不触发渲染。

## 根因

Milkdown Crepe v7.21.2 的 `preset-commonmark` 有图片的 InputRule（`![]()` → 图片），但**没有链接的 InputRule**。`LinkTooltip` 功能只提供已有链接的预览/编辑 UI，不处理输入时的自动转换。

需要添加一个自定义 ProseMirror InputRule，在输入 `](` 闭合时将 `[text](url)` 转换为带 link mark 的文本。

## 修改方案

### `src/components/MilkdownEditor.tsx`

1. 导入 Milkdown 插件 API（`$inputRule`、`$ctx` 等）和 ProseMirror `InputRule`
2. 创建一个自定义 Milkdown 插件，注册一个 markInputRule：
   - 匹配模式：`\[(?<text>[^\]]+)\]\((?<href>[^)]+)\)`（在输入 `)` 时触发）
   - 清除匹配的原始文本，重新插入带 `link` mark（href 属性）的文本
3. 在 Crepe 初始化时通过 `.use()` 注册该插件

关键参考：`@milkdown/preset-commonmark` 中的 `insertImageInputRule` 实现模式（匹配 `![]()` 并插入 image 节点），改造为匹配 `[]()` 并应用 link mark。

### 具体代码

在 `MilkdownEditor.tsx` 中添加：

```ts
import { InputRule } from '@milkdown/kit/prose/inputrules'
import { schemaCtx } from '@milkdown/kit/core'
import { $inputRule } from '@milkdown/kit/utils'

const linkInputRule = $inputRule((ctx) => {
  const linkMarkType = ctx.get(schemaCtx).marks.link
  return new InputRule(
    /\[([^\]]+)\]\(([^)]+)\)$/,
    (state, match, start, end) => {
      const [full, text, href] = match
      if (!full) return null
      const { tr } = state
      const linkMark = linkMarkType.create({ href, title: null })
      tr.replaceWith(start, end, state.schema.text(text, [linkMark]))
      return tr
    }
  )
})
```

在 Crepe 构造中注册：`crepe.editor.use(linkInputRule)`

## 涉及文件
- `src/components/MilkdownEditor.tsx`

## 验证
1. `npm run tauri dev` 启动应用
2. 在编辑器中输入 `[test](https://example.com)`
3. 输入最后一个 `)` 时应自动转换为可点击链接
4. 链接应有下划线样式（milkdown.css 中已有 `.ProseMirror a` 样式）
5. 鼠标悬停应显示 LinkTooltip 预览
