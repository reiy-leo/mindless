# 合并 group-form 和 list-form overlay

## 目标
两个 overlay 都是"名称+图标+颜色"表单，合并为一个通用 overlay。overlay 只负责输入输出，调用方自己决定调什么 API。

## 输入输出
- **输入**: `{name, icon, color, namePlaceholder?, isEditing?, showDelete?}`
- **输出**: `{action: 'submit', name, icon, color}` | `{action: 'delete'}` | `{action: 'cancel'}`

## 改动

### 1. `src/pages/overlays/GroupFormOverlayPage.tsx`
- payload 增加 `showDelete?: boolean`
- state 增加 `showDelete`
- 底部按钮区：左边显示 Delete 按钮（当 showDelete 为 true），emit `{action: 'delete'}`

### 2. 删除 `src/pages/overlays/ListFormOverlayPage.tsx`

### 3. `src/lib/overlayManager.ts`
- 删除 `list-form-overlay` 定义和 `LIST_FORM_LABEL`

### 4. `src/App.tsx`
- 删除 `ListFormOverlayPage` import 和 `/overlay/list-form` 路由

### 5. `src/pages/TasksPage.tsx`
- import 改：`LIST_FORM_LABEL` → `GROUP_FORM_LABEL`
- `handleCreateList`: `showOverlay(GROUP_FORM_LABEL, ...)` payload 加 `showDelete: false`
- `handleEditList`: `showOverlay(GROUP_FORM_LABEL, ...)` payload 加 `showDelete: true`
- 监听器：`list-form-overlay:result` → `group-form-overlay:result`
- 收到 submit 后调 `api.createList` / `api.updateList`，收到 delete 后调 `api.deleteList`

### 6. `src/components/ui/GroupFormPopup.tsx`
- props 增加 `showDelete?: boolean` 和 `onDelete?: () => void`
- 传递给 overlay payload
- 监听 delete action，调用 `onDelete` 回调
