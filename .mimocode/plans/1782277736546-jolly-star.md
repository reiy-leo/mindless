---

## 3. 优先级迁移 (`src-tauri/src/db/migrations.rs`)

新增迁移步骤：将现有任务的 priority 值 1→3, 2→6, 3→9：
```sql
UPDATE tasks SET priority = 9 WHERE priority = 3;
UPDATE tasks SET priority = 6 WHERE priority = 2;
UPDATE tasks SET priority = 3 WHERE priority = 1;
```
注意：必须先处理 3→9，再处理 2→6，再处理 1→3，避免值冲突。

## 6. SettingsPage 新增任务选项卡 (`src/pages/SettingsPage.tsx`)

### 6a. 扩展 tab 类型
```ts
useState<'general' | 'theme' | 'datetime' | 'sync' | 'shortcuts' | 'tasks'>
```

### 6b. 新增 tab 入口
在 tabs 数组中添加：
```ts
{ icon: ListTodo, id: 'tasks', label: t('settings.tabs.tasks') }
```
使用 lucide-react 的 `ListTodo` 图标。

### 6c. 从 General 移除优先级区块
删除 lines 514-551 的优先级设置 section。

### 6d. 新增任务选项卡内容
4 个 section：

**Section 1: 默认展示的功能**
- 6 个图标 toggle 按钮，照搬 TasksPage.tsx lines 707-737 的样式
- 图标：QueueListIcon(steps), TableCellsIcon(subtasks), PaperClipIcon(attachments), DocumentIcon(notes), IdentificationIcon(persons), FilmIcon(media)
- 状态来自 `defaultTaskSections` store 字段

**Section 2: 默认打开**
- 3 个 radio 选项：最后打开的视图 / 今天 / 收件箱
- 状态来自 `defaultTaskOpenView` store 字段

**Section 3: 优先级**
- 2 个 radio 选项：传统(4级) / 缺氧(11级)
- 从 General tab 搬过来，样式不变
- 状态来自已有的 `priorityMode` store 字段

**Section 4: 添加到今天**
- 4 个 radio 选项：00:00 / 06:00 / 12:00 / 18:00
- 状态来自 `todayResetHour` store 字段

## 7. TasksPage 应用默认设置

### 默认展示功能
- `TaskDetailPanel` 的 `visibleSections` 初始值从硬编码改为读取 `defaultTaskSections`

### 默认打开视图
- TasksPage 初始化时，如果 `defaultTaskOpenView === 'today'` 则 `selectedListId = 'smart:today'`
- 如果 `'inbox'` 则 `selectedListId = 'inbox'`
- 如果 `'last'` 则保持现有行为（记住上次选择）
