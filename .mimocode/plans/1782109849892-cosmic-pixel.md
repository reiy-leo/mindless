# Sync Tab Implementation Plan

## Overview
Add a "同步" (Sync) tab to Settings. Users configure a GitHub/GitLab repo URL + PAT, test connectivity, and sync app data (DB) to the repo. PAT stored in system keychain.

## Scope
- GitHub + GitLab only (Gitee deferred)
- Both use Octokit (GitLab via custom baseUrl)
- DB file synced as `mindless-data/mindless.json` (exported JSON) and `mindless-data/mindless.db` (raw file)

## Files to Change

### 1. `npm install @octokit/rest`

### 2. Rust: `src-tauri/Cargo.toml` — add `keyring` crate
For secure PAT storage in system keychain.

### 3. Rust: `src-tauri/src/commands/data.rs` — add commands
- `get_db_base64(app) -> String` — read mindless.db as base64
- `get_app_data_dir(app) -> String` — return app data dir path

### 4. Rust: `src-tauri/src/commands/sync.rs` — new file
Keychain operations:
- `save_pat(service, account, pat)` — save to keychain
- `load_pat(service, account) -> Option<String>` — read from keychain
- `delete_pat(service, account)` — delete from keychain

Keychain service name: `"mindless-sync"`, account: repo domain.

### 5. Register commands in `src-tauri/src/lib.rs` and `commands/mod.rs`

### 6. New file: `src/lib/syncService.ts`
```
parseRepoUrl(url) -> { domain, owner, repo } | null
  - Validate domain: github.com or gitlab.com
  - Regex: ^https?://(github\.com|gitlab\.com)/([^/]+)/([^/]+?)(?:\.git)?$

createOctokit(pat, domain) -> Octokit
  - github.com: default
  - gitlab.com: baseUrl = https://gitlab.com/api/v4 (uses GitLab's GitHub-compat API)

testConnection(pat, repoUrl) -> { success, error? }
  - Upload mindless-test.txt ("This is a attempt to upload mindless data")
  - Read it back, verify content
  - Delete test file
  - Return success/error

syncToRepo(pat, repoUrl, dbBase64, exportJson) -> { success, error? }
  - Upload exportJson to mindless-data/mindless.json
  - Upload dbBase64 to mindless-data/mindless.db
  - Uses uploadFile() helper that checks existing SHA for updates
```

### 7. API layer: `src/lib/api.ts`
```ts
getDbBase64(): Promise<string>
getAppDataDir(): Promise<string>
savePat(account: string, pat: string): Promise<void>
loadPat(account: string): Promise<string | null>
deletePat(account: string): Promise<void>
```

### 8. Settings page: `src/pages/SettingsPage.tsx`
- Add `'sync'` to activeTab type union
- Add `{ id: 'sync', label: t('settings.tabs.sync'), icon: Cloud }` to tabs array
- Add sync tab section with:
  - Repo URL input
  - PAT input (type="password")
  - "测试" button → testConnection
  - "同步" button → syncToRepo
  - Status message area
- State: `syncUrl`, `syncPat`, `syncStatus`, `syncLoading`
- PAT loaded from keychain on mount, saved on blur

## Verification
1. `cargo check` — Rust compiles
2. `npx tsc --noEmit` — TypeScript compiles
3. `npm run tauri dev` — app launches, sync tab visible
4. Enter GitHub repo URL + PAT → "测试" → success
5. "同步" → verify `mindless-data/mindless.json` appears in repo
6. Repeat for GitLab
7. Invalid URL → error message
