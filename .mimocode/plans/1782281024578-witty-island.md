# Attachment Management Dialog - Implementation Plan

## Overview
Create a standalone Tauri WebviewWindow dialog that lists ALL attachments across all tasks, with local cache and GitHub status indicators.

---

## Step 1: New Rust Commands

**File**: `src-tauri/src/commands/attachments.rs`

Add 3 new commands:

### 1a. `get_all_attachments`
```rust
#[tauri::command]
pub async fn get_all_attachments(app: AppHandle) -> Result<Vec<Attachment>, String>
```
- SQL: `SELECT id, task_id, original_filename, filename, added_datetime, sha256, local_path FROM attachments ORDER BY added_datetime DESC`

### 1b. `update_attachment_filename`
```rust
#[tauri::command]
pub async fn update_attachment_filename(app: AppHandle, id: String, original_filename: String) -> Result<(), String>
```
- SQL: `UPDATE attachments SET original_filename = ?1 WHERE id = ?2`

### 1c. `delete_attachment_local_cache`
```rust
#[tauri::command]
pub async fn delete_attachment_local_cache(app: AppHandle, id: String) -> Result<(), String>
```
- Read `local_path` from DB, delete the file if exists
- SQL: `UPDATE attachments SET local_path = NULL WHERE id = ?1`

## Step 4: React Query Hooks

**File**: `src/queries/useTaskQueries.ts` (append after line 454)

```typescript
export function useAllAttachments() {
  return useQuery({
    queryKey: ['all-attachments'],
    queryFn: () => api.getAllAttachments(),
  });
}

export function useUpdateAttachmentFilename() {
  const queryClient = useQueryClient();
  return useMutation({
    mutationFn: (params: { id: string; originalFilename: string }) =>
      api.updateAttachmentFilename(params),
    onSuccess: () => {
      queryClient.invalidateQueries({ queryKey: ['all-attachments'] });
    },
  });
}

export function useDeleteAttachmentLocalCache() {
  const queryClient = useQueryClient();
  return useMutation({
    mutationFn: (id: string) => api.deleteAttachmentLocalCache(id),
    onSuccess: () => {
      queryClient.invalidateQueries({ queryKey: ['all-attachments'] });
    },
  });
}
```

## Step 6: Dialog Component

**New file**: `src/pages/dialogs/AttachmentManagementDialogPage.tsx`

Structure (modeled after TagManagementDialogPage):

```
AttachmentManagementDialogPage
├── OverlayWebviewWindow (closable={false})
│   └── div.flex.h-full (full width, single panel)
│       ├── Header (data-tauri-drag-region)
│       │   ├── Close button (macOS traffic-light)
│       │   ├── Search input
│       │   └── Title "附件管理"
│       └── Attachment list (scrollable)
│           └── AttachmentRow (for each attachment)
│               ├── File icon (DocumentIcon)
│               ├── Filename (double-click → inline edit)
│               ├── Datetime (addedDatetime, formatted)
│               ├── ServerIcon (local cache status) + right-click context menu
│               └── WindowIcon (GitHub status) + async check
```

### Key behaviors:

**AttachmentRow** component:
- Shows `originalFilename` as text, double-click enters inline edit mode (input field, Enter to save, Escape to cancel)
- Shows `addedDatetime` formatted nicely
- `ServerIcon`: `localPath !== null` → theme color, else gray. Tooltip shows status text.
- `WindowIcon`: Initially shows as loading/spinner, then async checks GitHub → theme color if exists, gray if not.
- Right-click on `ServerIcon` opens context menu with:
  - "Delete local cache" → calls `deleteAttachmentLocalCache` mutation
  - "Fetch from GitHub" → downloads from GitHub, calls `cacheAttachmentImage`, refreshes

**GitHub check logic** (in useEffect on mount):
- Parse sync URL from localStorage
- Load PAT
- For each attachment, call `getFileSha(octokit, owner, repo, 'attachments/' + filename)`
- Store results in a `Map<string, boolean>` state
- Show loading indicator while checking

**Double-click rename**:
- Enter inline edit mode
- On Enter/blur → call `updateAttachmentFilename` mutation
