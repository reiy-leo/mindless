# 任务模板功能实现计划

## 需求概要
1. 新建任务底部工具栏添加「模板」按钮，选择模板直接新建任务
2. 任务右键菜单添加「保存为模板」
3. 模板保存：标题、描述、步骤、标签（不含日期时间、优先级）
4. 侧边栏底部添加模板按钮，Cmd+M 快捷键打开
5. 菜单栏-导航添加「管理"任务模板"」
6. 模板管理窗口：仿照 TagManagement，可删除/改名，展示名称、创建日期、修改日期、使用次数；双击名称修改，Enter 保存

## 实现步骤

### Step 1: 数据库 — 新建 task_templates 表
**文件**: `src-tauri/src/db/migrations.rs`

在 `run_migrations()` 末尾追加：
```sql
CREATE TABLE IF NOT EXISTS task_templates (
  id TEXT PRIMARY KEY,
  name TEXT NOT NULL,
  description TEXT,
  steps TEXT,
  tag_ids TEXT,
  usage_count INTEGER NOT NULL DEFAULT 0,
  created_at TEXT NOT NULL,
  updated_at TEXT NOT NULL
)
```

### Step 2: Rust 模型
**新建文件**: `src-tauri/src/commands/task_templates.rs`

定义 `TaskTemplate` 结构体（#[serde(rename_all = "camelCase")]），字段：id, name, description, steps, tag_ids, usage_count, created_at, updated_at

实现 5 个 Tauri command：
- `get_task_templates` → SELECT * ORDER BY updated_at DESC
- `get_task_template_by_id` → SELECT WHERE id = ?1
- `create_task_template` → INSERT（UUID 生成 id，时间戳）
- `update_task_template` → UPDATE（name, description, steps, tag_ids, updated_at）
- `delete_task_template` → DELETE WHERE id = ?1
- `increment_template_usage` → UPDATE usage_count = usage_count + 1, updated_at = ?1

### Step 3: 注册 Rust command
**文件**: `src-tauri/src/commands/mod.rs` — 添加 `pub mod task_templates;`
**文件**: `src-tauri/src/lib.rs` — 在 `generate_handler![]` 中注册 6 个 command

### Step 4: 前端类型 + API + Query
**新建文件**: `src/types/taskTemplate.ts`
```ts
export interface TaskTemplate {
  id: string
  name: string
  description?: string
  steps?: string   // JSON array
  tagIds?: string
  usageCount: number
  createdAt: string
  updatedAt: string
}
```

**文件**: `src/lib/api.ts` — 添加 6 个 invoke wrapper 函数

**文件**: `src/queries/useTaskQueries.ts`（或新建 `src/queries/useTaskTemplateQueries.ts`）— React Query hooks: `useTaskTemplates`, `useCreateTaskTemplate`, `useUpdateTaskTemplate`, `useDeleteTaskTemplate`, `useIncrementTemplateUsage`

### Step 5: 模板管理窗口
**新建文件**: `src/pages/dialogs/TaskTemplateManagementDialogPage.tsx`

仿照 TagManagementDialogPage，单面板布局（模板无需树形结构）：
- macOS 交通灯关闭按钮（与 TagManagement 一致）
- 搜索栏 + 新建按钮
- 列表：表格形式，列 = 名称、创建日期、修改日期、使用次数
- 双击名称进入编辑模式，Enter 保存，Escape 取消
- 右键菜单：删除（红色）
- 无模板时显示空状态

**文件**: `src/App.tsx` — 注册路由 `/dialog/task-template-management`

### Step 6: 侧边栏入口
**文件**: `src/components/layout/Sidebar.tsx`

在 Tags 和 Attachments 之间添加模板按钮：
- 图标：lucide `ClipboardListIcon`（或 `FileTextIcon`）
- 点击打开模板管理窗口（`WebviewWindow`，label = `task-template-management`，640x500）
- labelKey: `navigation.templates`

### Step 7: 快捷键 + 菜单栏
**文件**: `src/hooks/useKeyboardShortcuts.ts`
- 添加 `Cmd+M` → 打开模板管理窗口

**文件**: `src-tauri/src/menu.rs`
- Navigation submenu 添加 `manage_task_templates` 菜单项，accelerator `CmdOrCtrl+M`
- `MenuLabels` struct 添加 `manage_task_templates` 字段

**文件**: `src/hooks/useMenuEvents.ts`
- 添加 `manage_task_templates` case → `openDialog('task-template-management', ...)`

### Step 8: 新建任务工具栏 — 模板按钮
**文件**: `src/pages/TasksPage.tsx`

在 inline task form 底部工具栏（Attachment 按钮后方）添加模板按钮：
- 图标：`ClipboardDocumentIcon`（lucide）
- 点击弹出模板列表 popup（绝对定位，类似 Priority picker 的 popup 方式）
- 列表展示所有模板名称，选择后：
  - `setNewTaskTitle(template.name)`
  - `setNewTaskDescription(template.description || '')`
  - 解析 `template.steps` JSON → 创建 steps
  - `setNewTaskTagIds(template.tagIds ? template.tagIds.split(',') : [])`
  - `incrementTemplateUsage(template.id)`
- 需要新增 state: `showTemplatePicker`

### Step 9: 任务右键菜单 — 保存为模板
**文件**: `src/pages/TasksPage.tsx`

在右键菜单「删除」按钮之前、分隔线之后添加「保存为模板」：
- 图标：`BookmarkIcon` 或 `ClipboardDocumentCheckIcon`
- 点击后：
  1. 读取当前任务的 title, description, steps, tagIds
  2. 调用 `createTaskTemplate({ name: task.title, description, steps: JSON, tagIds })`
  3. 显示 toast 提示「已保存为模板」
  4. 关闭菜单
