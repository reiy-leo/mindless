# Bug Fix: 模板删除后 inline 列表未同步

## 根因
模板管理对话框在独立的 `WebviewWindow` 中运行，有独立的 React Query 缓存。删除模板时 `invalidateQueries(['task-templates'])` 只刷新对话框窗口的缓存，主窗口的缓存未失效。

## 修改文件
`src/components/layout/Sidebar.tsx`

## 实现

1. 导入 `useQueryClient` from `@tanstack/react-query`
2. 在 `Sidebar` 组件中获取 `queryClient`
3. 在 `handleOpenTemplateManagement` 的 `tauri://destroyed` 回调中 invalidate `['task-templates']`

```ts
win.once('tauri://destroyed', () => {
  templateWinRef.current = null
  queryClient.invalidateQueries({ queryKey: ['task-templates'] })
})
```

## 验证
1. 打开模板管理窗口，删除一个模板，关闭窗口
2. 点击 inline 新建任务区域的模板按钮 → 已删除的模板不在列表中
