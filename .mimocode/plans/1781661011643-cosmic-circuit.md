# 标签弹窗左右布局重构计划

## 目标
将现有 TagsPage 重构为左右分栏布局：左侧标签树（含右键菜单 + 拖拽排序），右侧简化编辑表单。

## 变更文件

### 1. `src/pages/TagsPage.tsx` — 主要重构
- **布局**: 替换为 `flex` 左右分栏，左侧 `w-72` 标签树面板，右侧编辑区占剩余空间
- **左侧标签树**:
  - 保留现有 `DndContext` + `SortableContext` 拖拽实现
  - 保留搜索框 + 新建按钮
  - 新增：点击标签项时，将该标签设为 `selectedTag`，右侧显示编辑表单
  - 新增：右键菜单组件 `ContextMenu`，定位到鼠标位置，包含三个选项：
    - **解散**: 将子标签的 `parentId` 设为当前标签的 `parentId`（子标签上移一层），然后删除当前标签。调用 `moveTags` + `deleteTag`
    - **前移**: 将当前标签的 `sortOrder` 减小（与同级前一个标签交换 `sortOrder`），调用 `moveTags`
    - **后移**: 将当前标签的 `sortOrder` 增大（与同级后一个标签交换 `sortOrder`），调用 `moveTags`
- **右侧编辑区**:
  - 简化表单：名称、emoji 选择器、颜色选择器、保存/取消按钮
  - 无选中标签时显示空状态提示
  - 删除原来的 `TagFormDialog` 弹窗组件，编辑功能内联到右侧

### 2. `src/i18n/locales/zh/common.json` + `en` + `ja` — 新增 i18n key
- `tags.dissolve` — 解散
- `tags.move_forward` — 前移
- `tags.move_backward` — 后移
- `tags.select_to_edit` — 选择标签进行编辑

## 实现细节

### 右键菜单
- 使用 `useState` 管理 `{ x, y, tag }` 状态
- `onContextMenu` 事件触发，`e.preventDefault()` 阻止默认菜单
- 点击菜单项或页面其他区域关闭菜单（`useEffect` 监听 `mousedown`）

### 解散操作逻辑
```typescript
function handleDissolve(tag: Tag) {
  const children = tags.filter(t => t.parentId === tag.id);
  // 1. 将子标签移到当前标签的父级下
  const moves = children.map((child, i) => ({
    id: child.id,
    parentId: tag.parentId || '',
    level: tag.level,  // 子标签层级不变（因为父级的 level 和当前标签相同）
    sortOrder: tag.sortOrder + 0.1 * (i + 1),
  }));
  moveTags.mutate(moves);
  // 2. 删除当前标签
  deleteTag.mutate(tag.id);
}
```

### 前移/后移逻辑
- 获取同级标签列表（相同 `parentId`），按 `sortOrder` 排序
- 前移：与上一个交换 `sortOrder`
- 后移：与下一个交换 `sortOrder`
- 调用 `moveTags.mutate()` 批量更新

### 拖拽排序
- 保留现有 `@dnd-kit` 实现，支持跨层级拖拽
- `handleDragEnd` 逻辑不变

## 验证方式
1. `npm run tauri dev` 启动开发模式
2. 点击侧边栏 Tags 图标，验证弹窗左右布局

4. 右侧：点击标签后显示编辑表单，修改后保存验证
5. 解散：验证子标签上移、原标签被删除
6. `npm run build` 验证无编译错误
