# 任务级别 visibleSections 存储

## 当前状态

- `visibleSections` 是 `TaskDetailPanel` 的本地 `useState`
- 初始化来源：全局设置 `defaultTaskSections`（`settings` 表 `default_task_sections` 键）
- 切换任务时不会按任务重置
- 没有按任务持久化

### 6. TaskDetailPanel 逻辑 — `src/pages/TasksPage.tsx`

**初始化**（line 325-330）：从任务的 `visibleSections` 或全局默认值初始化
```tsx
const defaultTaskSections = useAppStore((s) => s.defaultTaskSections)
const [visibleSections, setVisibleSections] = useState<Record<string, boolean>>(() => {
  if (task.visibleSections) {
    try { return JSON.parse(task.visibleSections) } catch {}
  }
  return { ...defaultTaskSections }
})

// 切换任务时重置
useEffect(() => {
  if (activeTask.visibleSections) {
    try {
      setVisibleSections(JSON.parse(activeTask.visibleSections))
      return
    } catch {}
  }
  setVisibleSections({ ...defaultTaskSections })
}, [activeTask.id, activeTask.visibleSections, defaultTaskSections])
```

**toggleSection**（line 320-322）：切换时保存到数据库
```tsx
const toggleSection = useCallback((key: string) => {
  setVisibleSections((prev) => {
    const next = { ...prev, [key]: !prev[key] }
    onUpdateTask({ visibleSections: JSON.stringify(next) })
    return next
  })
}, [onUpdateTask])
```

`onUpdateTask` 已通过 `handleUpdateTaskField` 传入，会自动使用当前任务 ID。

## 验证

1. 打开任务 A，关闭"步骤"面板 → 数据库 tasks 表该行 visible_sections 有值
2. 切换到任务 B → 显示全局默认值
3. 回到任务 A → "步骤"仍关闭
4. 重启应用 → 任务 A 设置持久化
