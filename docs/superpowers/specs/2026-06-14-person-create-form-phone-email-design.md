# 新建人员表单添加邮箱和手机字段设计

## 概述
在新建人员表单（PersonCreateForm）中添加邮箱和手机字段，支持类似任务步骤的交互方式，允许同时输入备注。

## 需求
1. 在新建人员表单中添加邮箱和手机字段
2. 支持添加多个邮箱和手机
3. 每次输入时可以同时输入备注
4. 交互方式类似任务步骤（内联添加、按Enter提交）
5. 字段为可选

## 设计

### 交互流程
1. 点击"+"按钮展开输入区域
2. 输入区域包含：
   - 手机号/邮箱输入框
   - 备注输入框（可选）
   - 标签选择（手机/工作/家庭/邮箱/个人/其他）
3. 按Enter或点击保存按钮提交
4. 列表显示：标签 + 值 + 备注 + 删除按钮

### 显示格式
```
📱 手机: 13800138000 (主要联系方式)
📧 邮箱: work@example.com (工作邮箱)
```

### 数据结构
```typescript
interface PhoneEntry {
  id: string;
  label: string;
  value: string;
  note: string;
}

interface EmailEntry {
  id: string;
  label: string;
  value: string;
  note: string;
}
```

### 组件结构
1. `PhoneEmailListEditor` - 新组件，统一处理手机和邮箱列表
   - 支持类型（phone/email）
   - 内联添加表单
   - 列表显示
   - 删除功能

2. 在 `PersonCreateForm` 中集成
   - 添加手机列表
   - 添加邮箱列表
   - 保存时将数据传递给创建API

### 标签选项
- 手机类型：手机、工作、家庭、其他
- 邮箱类型：邮箱、工作、个人、其他

## 实现步骤
1. 创建 `PhoneEmailListEditor` 组件
2. 修改 `PersonCreateForm` 添加手机和邮箱字段
3. 修改创建人员的API调用，传递手机和邮箱数据
4. 测试交互流程
