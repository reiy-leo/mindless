                    数据流架构图

用户交互
   ↓
┌─────────────────────────────────┐
│   React Components (UI Layer)   │
│   - TaskItem, HabitItem, etc.   │
└─────────────────────────────────┘
   ↓ 调用
┌─────────────────────────────────┐
│   Custom Hooks (Business Log)   │
│   - useTasks, useHabits, etc.   │
└─────────────────────────────────┘
   ↓ 使用
┌─────────────────────────────────┐
│   React Query (Data Fetching)   │
│   - useQuery, useMutation       │
└─────────────────────────────────┘
   ↓ 调用
┌─────────────────────────────────┐
│   Services (API Layer)          │
│   - taskService, habitService   │
└─────────────────────────────────┘
   ↓ 通过
┌─────────────────────────────────┐
│   Tauri Invoke (IPC Bridge)     │
│   - invoke('create_task', ...)  │
└─────────────────────────────────┘
   ↓ 执行
┌─────────────────────────────────┐
│   Rust Commands (Backend)       │
│   - create_task(), get_tasks()  │
└─────────────────────────────────┘
   ↓ 操作
┌─────────────────────────────────┐
│   Drizzle ORM + SQLite          │
│   - 类型安全的 SQL 查询          │
└─────────────────────────────────┘
   ↓ 存储
┌─────────────────────────────────┐
│   SQLite Database File          │
│   - app_data/mindless.db        │
└─────────────────────────────────┘

                    关键文件说明

🔧 配置文件:
  • tauri.conf.json       - Tauri 应用配置 (窗口、权限、构建)
  • package.json          - Node 依赖和脚本
  • Cargo.toml            - Rust 依赖

🗄️ 数据库相关:
  • drizzle/schema.ts     - 数据库表结构定义 (TypeScript)
  • drizzle/migrations/   - SQL 迁移文件
  • src-tauri/src/db/     - Rust 数据库连接和迁移逻辑

🌍 国际化:
  • src/i18n/config.ts    - i18next 初始化配置
  • src/i18n/locales/*/   - 三语翻译文件 (zh/en/ja)

🎨 UI 组件:
  • src/components/ui/    - 基础 UI 组件 (Radix UI)
  • src/components/layout/- 应用布局组件
  • src/components/*/     - 功能模块组件

📊 状态管理:
  • src/stores/           - Zustand stores (全局状态)
  • src/queries/          - React Query hooks (服务端状态)

🔌 Tauri 集成:
  • src-tauri/src/commands/ - Rust 命令 (前端可调用的 API)
  • src/lib/api.ts        - Tauri invoke 封装


================================================================================
                    开发工作流
================================================================================

1️⃣  启动开发服务器:
    $ npm run tauri dev
    
    → 同时启动:
      - Vite 开发服务器 (React 前端, localhost:1420)
      - Tauri 应用窗口 (Rust 后端)
      - 热重载 (HMR) 支持

2️⃣  修改代码:
    前端: 编辑 src/ 下的 React 组件
    后端: 编辑 src-tauri/src/ 下的 Rust 代码
    
    → 自动重新编译和刷新

3️⃣  数据库变更:
    a. 修改 drizzle/schema.ts
    b. 运行: npx drizzle-kit generate
    c. 重启应用自动执行迁移

4️⃣  添加新翻译:
    a. 在 src/i18n/locales/{zh,en,ja}/ 添加 key
    b. 使用 useTranslation hook: t('key')

5️⃣  构建生产版本:
    $ npm run tauri build
    
    → 生成:
      - macOS: src-tauri/target/release/bundle/dmg/*.dmg
      - 优化后的二进制文件

  ✓ Zustand (全局状态)

后端:
